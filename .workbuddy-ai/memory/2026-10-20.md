# 2026-10-20

## Shree Keshri Synthetics — brand site (built from scratch)

- Stack: Vite 5 + React 18 + TypeScript + Tailwind 3.4 + framer-motion + lucide-react.
  shadcn-style layout (`src/components/ui`, `@/` alias), single-page marketing site.
- Installed the `ui-ux-pro-max` skill to both `~/.workbuddy-ai/skills/` and
  `.workbuddy-ai/skills/`; used `--design-system` for direction (Cormorant/Montserrat
  suggested, overridden to Playfair Display + Inter + JetBrains Mono for a warmer
  editorial feel; palette kept light-paper + near-black text + maroon/gold from the logo).
- Source images were phone snapshots (OPPO watermark bottom-left). Processed with Pillow:
  cropped out the watermark, graded warm, produced 3:4 collection tiles, a 4:5 owner
  portrait, a circular `logo-mark.png` (masked, 256px) and `og.jpg`.
- Sections: Preloader (logo curtain) → Nav (scroll progress, mobile overlay) → Hero →
  ticker marquee → Collections (3 photo cards + "also in store") → maroon quote band →
  Story (interiors + 3 promises) → Owner → Visit (custom SVG map poster + click-to-load
  Google Maps embed) → CTA → halftone wordmark footer.
- Exact location wired everywhere: 25.720689, 86.595200 (25°43'14.48"N 86°35'42.72"E).
  JSON-LD ClothingStore schema in `index.html`.
- Gotcha fixed: `MaskLine` observed the *moving* child, which is fully clipped by its
  `overflow:hidden` parent, so IntersectionObserver never fired and headlines stayed
  hidden. Moved the observer to the clipping wrapper (`useInView` on the outer span).
- Build: `npm run build` → `dist/` (relative base, works from a static host).
